# 错误处理 · 假期系数日更

执行本技能遇到报错，先查本表，按脚本返回的 `code` / `exit code` 与 `next_action` 执行；禁止跳过查表自由发挥。

## 脚本错误（overlay_time.py）

| error_code | 动作 | 说明 |
|-----------|------|------|
| `INVALID_DAY` | 停止，修正日期后重试 | `--day` 不是 `YYYY-MM-DD` |
| `INVALID_ID` | 停止，修正模板 ID 后重试 | 模板 ID 非整数或不在 26558、26559 |
| `UV_NOT_FOUND` | 停止，引导安装 uv | 系统未安装 uv，禁止降级 python3/pip |

## 接口流程错误（Agent 编排层）

| 情况 | 动作 | 说明 |
|------|------|------|
| 鉴权失败（302 / 401 / HTML login） | 整轮中止 + 告警 | 停止空转重试，不改用 Data Agent |
| 单条 get 空壳 / 失败 | 跳过该条，继续下一条 | 四条全失败则整轮失败告警 |
| HTTP 4xx（含 412） | 收紧白名单字段后同条最多再试 1 次 | 仍失败则记该条失败，不硬切模式 |
| HTTP 5xx | 立即中止该条，不重试 | 服务端故障，稍后重试 |
| 审核流转被拒但已灰度 | 旁路 `quickPushAll`（仅开启推全时） | 否则记「待人工」 |
| 部分成功 | 汇报成功/失败明细，不算整轮成功 | 不静默吞掉 |

## 通用环境错误

| error_code | 动作 | 对用户说 |
|-----------|------|----------|
| `UV_NOT_FOUND` | 停止，禁止降级 python3/pip | 当前系统未安装 uv 工具，请执行 `curl -LsSf https://astral.sh/uv/install.sh | sh`（或 `brew install uv`），安装后回复「已安装」 |
| `AUTH_EXPIRED` | 停止，引导重新登录 | Auth Token 已过期，请在浏览器访问任意 example.corp 页面完成认证后回复「已登录」 |
| `API_TIMEOUT` | 重试 1 次，仍失败则中止 | 请求超时（已重试 1 次仍失败），请检查网络（是否已连 VPN） |
| `API_5XX` | 立即中止，不重试 | 目标服务暂时不可用（5xx），请稍后重试 |
| `AUTH_FAILED` | 停止，抛给用户 | 当前账号无权限执行该操作，请联系管理员开通权限 |
