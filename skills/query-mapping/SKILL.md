# Query Mapping

## 使用原则

当用户要查询或生成查询口径时，识别并整理这些维度：

- 时间与时间对比维度
- 流量主维度：`uid`、`appid`、`posid`
- 广告主维度
- 广告场景维度
- 转化目标（原优化目标）

默认规则：

- 用户不提供某个维度时，默认不添加该维度。
- 用户不提供时间时，默认时间为 `T-1`。
- 用户不提供对比时间时，默认对比为 `T-1 vs T-2`。

## 时间与数据集

- 数据集 `85587`（离线）：适用于 `T-1` 与历史数据。
- 数据集 `129496`（实时）：仅当用户明确要求“实时”且查询“当天数据”时使用。
- 支持对比维度：日同比、周同比、季同比、年同比。
- 日均：一段时间内数据的平均值，总量除以天数，表示平均每天的典型水平。
- 汇总：一段时间内数据的累加总和，所有数据直接相加。

## 流量主维度

用户可提供一个或多个 `uid`、`appid`、`posid`，并可混合提供。处理时：

1. 将用户提供的 ID 作为筛选条件，灵活组合。
2. 查询结果表格的展示维度自动转换为媒体名称。
3. 输出中展示媒体名称，不展示原始 ID，除非用户明确要求保留原始 ID。

字段映射：

| 字段中文名 | 字段说明 | 备注 |
| --- | --- | --- |
| 开发者ID (`uid`) | 流量主开发者唯一标识 | 数据集中可能显示为“开发者id” |
| 应用ID (`app_id`) | 开发者的应用唯一标识 | 可能显示为“应用id” |
| 广告位ID (`pos_id`) | 应用内的广告位标识 | 可能显示为“广告位id” |
| 媒体名称 | 开发者/应用的媒体名称 | ID 转换目标字段 |
| sdk类型 | SDK类型：1=纯广告，2=广告&内容，0=默认值 |  |
| sdk编码 | SDK编码 |  |
| 是否快应用APP | 是否为快应用类型 |  |
| 流量一级分类 | 根据流量二级分类映射 |  |
| 流量二级分类 | 根据 `uid`、`app_id`、`cooperation_mode` 划分 | 包含合作模式信息 |
| 合作模式 | 开发者合作模式 | 从流量二级分类注释推断存在 |
| 投放类型 | 明投/暗投 |  |

## 广告主维度

| 字段中文名 | 字段说明 |
| --- | --- |
| 广告主快手ID | 商业化广告账户对应的快手ID（`user_id`） |
| 广告主快手名称 | 广告主快手ID对应的名称，历史数据按最新名称关联 |
| 账户ID | 广告主投放广告使用的账号ID，经UC开户生成 |
| 集团 | 综合营业执照/快手ID打标的集团名，优先取营业执照打标 |
| 营业执照 | 广告主开户时填写并认证的营业执照名称 |
| 产品名称 | 广告主开户时填写的产品名/品牌名 |
| 账户一级行业名称 | 账户ID对应的一级行业，每季度由UC制定 |
| 账户二级行业名称 | 账户ID对应的二级行业 |
| 账户类型 | 账户ID对应的账户类型（`account_type`） |
| 计划ID | 广告主创编时生成的计划ID |
| 计划名称 | 计划ID对应的名称 |
| 单元ID | 广告组ID，单元与计划是 N:1 关系 |
| 创意ID | 广告创意ID，单元与创意是 1:N 关系 |

## 广告场景维度

| 字段中文名 | 字段说明 |
| --- | --- |
| 广告场景 | 联盟广告场景，如插屏、激励视频等 |
| 广告场景分层 | 广告场景的分层分类 |
| 多场景资源位（投放广告位） | 广告主在 DSP 上选择的投放位置，可多选 |
| 图标场景 | 联盟广告位图标场景 |
| sdk版本 | SDK版本号 |

## 转化目标维度

| 字段中文名 | 字段说明 |
| --- | --- |
| 转化目标（原优化目标） | 广告主选择的浅度转化目标，如激活、表单提交等，代表目标用户行为 |
| 转化目标类型 | 区分浅度目标/深度目标，根据转化目标和深度目标自动判断 |
| 深度目标 | 广告主选择的深度转化目标，双出价场景下才有意义 |

## 输出要求

响应用户时优先输出：

1. 选择的数据集及原因。
2. 时间范围与对比口径，说明是否使用默认值。
3. 筛选条件，尤其是 `uid`、`appid`、`posid` 的组合方式。
4. 展示维度与字段映射，流量主 ID 默认映射为媒体名称展示。
5. 需要用户补充的信息；只在无法判断查询目标时追问。
