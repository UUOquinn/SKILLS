# 129496 OLAP 快路径

## 定位

`olap_client.py` 只服务数据集 `129496` 的当天/实时查询。它走：

```text
POST https://bi-platform.example.corp/api/v1/data/query
```

携带 `Kwaibi-View-Query-Type: 8` + `kwaibi-request-module: olap`，底层由 OLAP 引擎执行。
`olap.corp` 域名直连在当前 SSO 环境不可用（401），不要改回直连。

85587 的离线查询仍由 `kwaibi_client.py` 处理，直到 Hive 表字段、分区及指标分子分母完成对账验证。

## 使用限制

- 模板必须是从可用 OLAP 看板抓到的完整请求体，且 `dataSetId=129496`；
- 模板中必须存在日期 `filterValue.startTime/endTime`，脚本会每次改写为当前请求的自然日范围；
- 模板自带业务过滤时，只能用于该业务；不能把短剧 IAA 模板误用于通用策略查询；
- 附加筛选只支持 `uid`、`app_id`、`pos_id` 三选一，单次最多 50 个同维度 ID；
- 结果中的数值来自响应 `r` 字段，而不是已格式化、可能带单位和四舍五入的 `v` 字段。

## 命令

```bash
uv run <skill_directory>/scripts/olap_client.py \
  --template <真实129496模板.json> \
  --start <epoch_ms> --end <epoch_ms> \
  --referer <对应OLAP看板URL> \
  --dim uid --ids 1,2,3
```

需要补跑一项时：

```bash
uv run <skill_directory>/scripts/olap_client.py ... --dim uid --item 1
```

## 数据准确性

- 当天实时与 T-1/历史数据不能混用；
- 需要比例指标时，必须确认模板已返回可重算的原始分子分母；禁止对分钟/小时比例做算术平均；
- 首次启用新模板或新指标时，用同一筛选和时间范围调用 KwaiBI `data/query` 抽样对账；
- OLAP 发生权限、模板字段、空结果或对账异常时，改走 KwaiBI 并在结果中说明数据来源。

## 流量侧维度消耗快捷查询

`kwaibi_client.py query-alias --data-set 129496` 支持 `--group-by scene|coop|mtype|deliver|opclass`，分别对应 129496 的「广告场景 / 合作模式 / 媒体类型_内外部 / 投放类型 / 联盟运营分类」。此命令复用 `references/olap_traffic_template.json` 的完整请求骨架、每次重写日期，并通过 `https://bi-platform.example.corp/api/v1/data/query` 携带 `Kwaibi-View-Query-Type: 8` 与 `kwaibi-request-module: olap` 查询；底层为 OLAP，但接入域名不是 `olap.corp`。支持 `uid`、`app_id`、`pos_id`，一次最多 50 个同维度 ID。

```bash
uv run <skill_directory>/scripts/kwaibi_client.py query-alias \
  --data-set 129496 --dim app_id --ids 540400001,1387000058 \
  --group-by scene --days 1
```

宽窗口或大量 ID 扫描超限时，按日且按最多 50 个 ID 分批，排除 `$ALL$` 汇总行，再本地相加。数据集 129496 没有确认存在名称恰为「流量分类(流量侧)」的字段，不要直接将「联盟运营分类」改名为该口径。
